## 背景
燈籠上的字原本規劃由 App 即時疊上 Yuji Syuku 毛筆字。實測效果太假（平貼、沒有弧面、不吃紙），改為**預先合成好字的燈籠圖**。字已依圓筒弧面變形，並以正片疊底吃進紅紙，竹骨紋會透出來。**App 不再在燈籠上即時寫字。**

## 要做的事
1. **首頁燈籠**：把首頁燈籠換成 `OB01_raimon.png`，刪掉所有在燈籠上疊「雷門」文字的程式。擺動的旋轉中心維持在頂環中央；圖的尺寸和舊 `OB01.png` 相同（896×1326），原本量好的 pivot 常數可以沿用，換完請目視確認一次。
2. **好籤時出現「成」燈籠**：
   - 觸發條件：**淺草寺百籤**抽到「大吉」或「吉」時。六十甲子籤沒有吉凶欄位，不觸發；凶籤走既有的結籤流程，也不觸發。
   - 位置與動態：06 籤詩頁籤紙展開完成後約 0.4 秒，`OB01_sei.png` 從畫面右上角沿一條吊繩緩緩降下（約 0.9 秒，ease-out，最後輕微回彈），停住後持續慢速擺動（幅度約 ±1.5°，週期約 6 秒），背後加一圈暖金色光暈 `#E3C68E`（低不透明度、緩慢呼吸）。寬度約為畫面寬的 22%，不能遮住籤詩文字與按鈕；位置與尺寸寫成常數。
   - 開啟「減少動態效果」時：不降下、不擺動、不呼吸，直接淡入並靜止顯示。
   - 籤紀錄回看該籤時同樣顯示。
3. **App 圖示換成「成」燈籠**：
   - Android：以 `IC01_icon_1024_sei.png` 產生一般圖示；自適應圖示用 `IC01_adaptive_fg_sei.png` 當前景、純色 `#F1EADC` 當背景。若專案已用 `flutter_launcher_icons`，更新設定後重新產生；沒有就加上。

   - 舊的 `IC01_icon_1024.png`、`IC01_lantern_cutout.png` 不再使用，不要刪原檔，只是不再引用。
4. **更新 `BUILD_PLAN.md`**：
   - 第 1 節素材表：OB01 改成 `OB01_raimon`（首頁）／`OB01_sei`（好籤），註明「字已合成在圖上，App 不疊字」。
